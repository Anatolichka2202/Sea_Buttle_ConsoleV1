# Sea Battle Console V1

Учебная консольная реализация морского боя. Репозиторий сохраняется как первая версия и история обучения; новая аккуратная реализация — отдельная задача.

## Где находится код

Основная ветка `main` содержит только это описание. Исходники учебной версии находятся в [ветке master](https://github.com/Anatolichka2202/Sea_Buttle_ConsoleV1/tree/master).

Готовая сборка и тестирование этой исторической версии здесь не подтверждены. Внешняя витрина должна ссылаться на ветку с кодом, а не выдавать `main` за полноценный исходный проект.
